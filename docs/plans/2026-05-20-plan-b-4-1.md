# Plan B-4.1: Real subscribe + publish via iroh-gossip — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace B-4.0's `NetError::Unimplemented` returns in `IrohNetwork::subscribe` + `IrohNetwork::publish` with real iroh-gossip 0.99.0-backed implementations; add `bootstrap: Vec<PeerPubkey>` to `Network::subscribe` (SemVer-breaking, all 7 call sites updated); add `SubError::DecodeFailed { peer }` (distinct from `SubError::Lagged` so the runtime does **not** flood `publish_heads_summary` on a single bad peer); add `NetError::SubscribeFailed(String)`; ship 5 acceptance tests covering single-hop, multi-hop, decode-failure, unsubscribe-still-unimplemented, and topic-id roundtrip.

**Architecture:** `iroh_gossip::Gossip::subscribe(topic_id, bootstrap_vec) → GossipTopic` returns a stream of `Result<Event, ApiError>`. Wrap it in `IrohSubscription { inner: GossipTopic }`; `recv()` loops over `inner.next().await`, surfacing `Event::Received` as a bincode-decoded `GossipMessage`, mapping `Event::Lagged` and stream-level `ApiError` to `SubError::Lagged(0)` (count fidelity lost), bincode-decode failures to `SubError::DecodeFailed { peer }`, and silently consuming `Event::NeighborUp` / `Event::NeighborDown`. `publish` re-subscribes (empty bootstrap), splits, and broadcasts `Bytes::from(canonical_bincode().serialize(&msg)?)`. `unsubscribe` still returns `NetError::Unimplemented` but with `planned_in: "B-4.2"` (drop semantics already cover practical "stop receiving"). `MemNetwork::subscribe` accepts and ignores `bootstrap` (in-process broadcast has no peer discovery).

**Tech Stack:** Rust 1.95 (edition 2024), iroh `=1.0.0-rc.0` + iroh-gossip `=0.99.0` (already pinned by B-4.0), new workspace deps `futures-lite = "2"` + `bytes = "1"` (feature-gated under `network-iroh`), tokio (existing).

**Spec:** `docs/specs/2026-05-20-plan-b-4-1-iroh-gossip-design.md` (audit-and-align cleared; residual cosmetic polish committed in `a95f036` pre-implementation).

**Branch:** `feat/plan-b-4-1-iroh-gossip` (already exists; 3 commits ahead of main: spec, audit revisions, residual polish).

```rust
/// Iroh-gossip-backed subscription.
///
/// Wraps a [`iroh_gossip::GossipTopic`] (a stream of
/// `Result<Event, ApiError>`), filters events to only surface
/// [`Event::Received`] payloads (decoded via canonical bincode),
/// maps [`Event::Lagged`] and stream-level `ApiError` to
/// [`SubError::Lagged(0)`] (count fidelity lost — see spec §6),
/// maps bincode-decode failures to [`SubError::DecodeFailed`], and
/// silently consumes membership events ([`Event::NeighborUp`],
/// [`Event::NeighborDown`]).
///
/// Per B-4.1 spec §3.2.
pub struct IrohSubscription {
    inner: GossipTopic,
}

impl IrohSubscription {
    /// Construct from a [`GossipTopic`] returned by
    /// `iroh_gossip::Gossip::subscribe`. Crate-private — callers
    /// reach this via [`IrohNetwork::subscribe`].
    pub(crate) fn new(inner: GossipTopic) -> Self {
        Self { inner }
    }
}

#[async_trait::async_trait]
impl Subscription for IrohSubscription {
    async fn recv(&mut self) -> Result<Option<GossipMessage>, SubError> {
        loop {
            match self.inner.next().await {
                None => return Ok(None),
                Some(Err(_api_err)) => {
                    // Stream-level error from iroh-gossip mid-flight.
                    // Surfacing as Lagged(0) is a pragmatic mapping —
                    // we lose error specifics but the runtime's
                    // Lagged path (HeadsSummary backfill) is the
                    // closest match for "I may have missed messages."
                    // TRADE-OFF: if the gossip task has actually died,
                    // we'll spin re-calling recv and getting ApiError
                    // forever. Halt detection is B-4.3's scope.
                    return Err(SubError::Lagged(0));
                }
                Some(Ok(Event::Received(msg))) => {
                    // Capture the last-hop neighbor for attribution
                    // on decode failure. NOT necessarily the original
                    // publisher (Plumtree forwarding hides that;
                    // Q-4 attribution is B-4.2 scope).
                    let last_hop_peer = Some(peer_pubkey_from_iroh(msg.delivered_from));
                    match canonical_bincode().deserialize::<GossipMessage>(&msg.content) {
                        Ok(decoded) => return Ok(Some(decoded)),
                        Err(_decode_err) => {
                            return Err(SubError::DecodeFailed {
                                peer: last_hop_peer,
                            });
                        }
                    }
                }
                Some(Ok(Event::Lagged)) => {
                    // Iroh-gossip drops the lagged count
                    // (`gossip/src/net.rs:940` discards it with `_`);
                    // sentinel 0 preserves the variant shape. Reclaiming
                    // count fidelity needs an upstream patch — out of
                    // scope for B-4.1.
                    return Err(SubError::Lagged(0));
                }
                Some(Ok(Event::NeighborUp(_))) | Some(Ok(Event::NeighborDown(_))) => {
                    // Membership events — silently consume + continue
                    // the loop. Surfacing through the trait would force
                    // every Subscription consumer to handle them; only
                    // IrohNetwork produces them.
                    continue;
                }
            }
        }
    }
}
```

/// Drain neighbor / lag events from a subscription until either a
/// `Received` message arrives (returns it) or the timeout fires
/// (panics). Used to handle the swarm-formation period during which
/// `recv()` may yield NeighborUp / NeighborDown.
async fn recv_first_decoded<S: Subscription>(sub: &mut S) -> GossipMessage {
    let result = timeout(Duration::from_secs(5), async {
        loop {
            match sub.recv().await {
                Ok(Some(m)) => return m,
                Ok(None) => panic!("subscription closed before message arrived"),
                Err(e) => panic!("recv returned unexpected error: {e:?}"),
            }
        }
    })
    .await;
    result.expect("timeout waiting for first decoded message")
}
