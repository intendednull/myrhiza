# B-7 Implementation Plan — Native Interaction Harness + Criterion 3

> **For agentic workers:** REQUIRED SUB-SKILL: Use `subagent-driven-development` to implement this plan task-by-task. Spec at [`docs/specs/2026-05-21-plan-b-7-interaction-harness-design.md`](../specs/2026-05-21-plan-b-7-interaction-harness-design.md) is the design contract; this plan is the execution order.

**Goal:** Ship v1 acceptance criterion 3 — a native CLI that loads a counter bundle, projects state via an interaction component, takes user input, dispatches through state-propose, applies the event via state-apply, observes the state change.

**Architecture:** 8 PR-sized slices in the order **B-7.0 → B-7.1 → B-7.2 → B-7.5 → B-7.6 → B-7.3 → B-7.4 → B-7.7**. Each slice is independently testable; later slices depend on earlier slices' types and fixtures.

**Tech Stack:** Rust 2024, wasmtime 27.x + wit-bindgen 0.30, BLAKE3, canonical bincode 1.3.3, Ed25519, tokio (existing kernel deps); no new heavy deps for B-7.

**Common workflow per slice:**
1. Dispatch implementer subagent with the slice's "Files" + "Steps" sections + spec section reference.
2. After implementer completes: dispatch spec-compliance reviewer.
3. After spec compliance ✅: dispatch code-quality reviewer.
4. After both ✅: commit and proceed.
5. After all 8 slices land: dispatch a fresh opus final-review agent across the entire branch before PR.
